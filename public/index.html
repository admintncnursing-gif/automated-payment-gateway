ArchXpay API documentation

1. Create a checkout

Send your approved API key and a positive INR amount. ArchXpay creates a unique payment link and dynamic UPI QR.

POST /api/v1/checkout/create
x-api-key: YOUR_API_KEY
Content-Type: application/json

{"amount":500,"customerName":"Customer","customerEmail":"customer@example.com","note":"Order 123"}
2. Check verification status

Poll the order status or open the returned checkoutUrl. The status becomes PAID only after the configured Gmail watcher matches a bank alert to the exact amount and reference.

GET /api/v1/checkout/status/PAY-ORDER-ID

{"success":true,"verified":true,"order":{"status":"PAID"}}
3. Gmail auto-verification

Enter the receiving Gmail account and Google 16-character App Password in merchant onboarding. Enable Gmail IMAP and 2-Step Verification in your Google account. App Passwords are used only by the server-side IMAP verifier.

Security and approval

API keys are issued only after administrator approval. Keep keys server-side, use HTTPS in production, and do not treat a manually entered UTR as proof by itself. Bank-authoritative settlement confirmation remains your responsibility.
